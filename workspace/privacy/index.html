1. 적용 범위와 운영자

이 방침은 ㈜에듀원큐(EDU ONEQ Corp.)가 내부 업무용으로 운영하는 EDU ONEQ Workspace(데스크톱 앱 EDUONEQ OS에서 접속하는 업무 포털)에 적용됩니다. 현재 지정된 Google 운영 계정과 허가된 사용자를 위한 서비스이며, 공개 회원가입 서비스가 아닙니다.

Workspace는 자료 검색·열람, AI 대화와 작업, 프로젝트 관리, 일정 확인, 결과 저장을 지원하며, 운영자가 켠 경우 법령·세무 자료 정리와 허가된 기기의 화면 작업도 지원합니다. 이 공개 페이지를 방문하는 것만으로 Google 계정이 연결되거나 Google 문서·일정이 수집되지는 않습니다. EDU ONEQ Workspace의 처리에는 이 방침이 적용되며, 회사 홈페이지 개인정보처리방침의 국외 이전(4-1)·API 데이터 처리(8-1) 조항 대신 이 방침의 4절·7절이 우선합니다. 회사 홈페이지의 일반 문의 등 다른 서비스는 회사 홈페이지 개인정보처리방침을 확인해 주세요.

3. Google 접근 권한과 이용 목적

Drive 읽기 drive.readonly

파일 목록과 문서 내용을 읽어 자료 검색·미리보기·사용자가 요청한 업무에 제공합니다. 전체 권한명은 https://www.googleapis.com/auth/drive.readonly입니다.

앱 관련 파일 관리 drive.file

사용자가 결과 저장이나 위키 반영(승인한 변경 내용을 앱이 만든 위키 문서에 적용)을 요청하면 새 Google Docs 문서·Drive 파일을 만들고, 이 앱이 만든 파일에만 내용을 기록·갱신합니다. 이 권한으로 접근할 수 있는 파일은 앱이 만들었거나 사용자가 앱에서 열도록 허용한 파일뿐이며, Drive 전체 파일의 수정 권한을 뜻하지 않습니다. 전체 권한명은 https://www.googleapis.com/auth/drive.file입니다.

Calendar 읽기 calendar.readonly

캘린더 목록과 선택한 캘린더 일정의 기간별 조회·상세 확인·업무 화면 표시를 위해 사용합니다. 현재 이 연결은 Google 일정 생성·수정·삭제를 수행하지 않습니다. 전체 권한명은 https://www.googleapis.com/auth/calendar.readonly입니다.

연결 이후 파일 목록의 변경 사항과 선택한 캘린더의 일정이 주기적으로 동기화될 수 있습니다. Google 연결은 내부 업무 화면과 별도로 Google 동의 화면에서 승인하며, 실제 승인한 권한에 따라 사용 가능한 기능이 달라집니다.

4. AI 처리와 외부 전송

사용자는 작업에 사용할 모델과 계정을 선택합니다. 내부 모델을 이용하면 내부 운영 환경에서 처리하며, 외부 AI를 선택하면 해당 요청의 대화·선택 자료·문맥과 첨부 내용이 선택한 사업자에게 전송될 수 있습니다. 현재 연결할 수 있는 외부 AI 사업자는 Anthropic(Claude, 구독 계정), OpenAI(ChatGPT, 구독 계정), xAI(Grok, API) 세 곳입니다. 이 목록 밖의 사업자로 Google 자료를 보내려면 먼저 이 방침을 갱신합니다. 법령·세무 대화에서 외부 AI를 선택하면 회사 설정 요약과 올린 통장 거래내역 요약도 함께 전송될 수 있습니다.

외부 전송은 사용자가 실행한 업무와 허용한 도구의 기능을 제공하기 위한 범위로 제한합니다. Google 자료를 받을 수 있는 외부 대상은 위 외부 AI 사업자와, 사용자가 설정에서 직접 추가·활성화한 커넥터(MCP 서버) 두 가지뿐입니다. 커넥터는 제3자가 운영하는 외부 서비스이거나 사용자가 지정한 서버이며, 사용자가 해당 요청에서 그 커넥터를 호출한 경우에만 요청 처리에 필요한 자료가 전달됩니다. 자료를 선택한 뒤 모델을 바꾸거나 후속 요청을 하면 해당 작업 문맥에 이미 포함된 자료도 함께 처리될 수 있습니다.

외부 사업자의 처리·보관 조건은 선택한 서비스, 계약 및 계정 설정에 따라 다릅니다. 운영자는 입력 자료를 AI·머신러닝 모델의 생성·학습·개선에 사용하지 않는 조건(API·기업 약관 또는 계정의 학습 사용 해제 설정)을 직접 확인한 외부 AI 계정만 Workspace에 연결하며, 이 조건을 확인하지 못한 서비스나 계정으로는 Google 자료를 보내지 않습니다. 이 확인은 계정을 연결할 때와 사업자 약관·설정이 바뀔 때 운영자가 직접 수행하며, Workspace가 외부 계정의 학습 설정을 자동으로 검증하거나 변경하지는 않습니다.

화면의 전송 안내와 설정을 확인하고 필요한 자료만 포함해 요청해 주세요. 별도 확인 창의 표시 여부는 설정에 따라 달라질 수 있으므로, 모든 요청에 새 동의 팝업이 표시된다고 보장하지 않습니다.

외부 AI 사업자로의 국외 이전. 외부 AI를 선택한 요청에서는 아래 사업자(모두 미국 소재)에게 개인정보가 포함될 수 있는 자료가 이전될 수 있습니다. 이전 항목은 해당 요청의 대화·선택 자료·문맥·첨부 내용(Drive 문서 본문과 일정 정보 포함 가능)이며, 사용자가 해당 모델로 요청을 실행하는 시점에 암호화된 연결(HTTPS)로 전송됩니다. 이용 목적은 요청한 응답의 생성이고, 보유 기간은 각 사업자의 약관과 계정 설정에 따릅니다. 외부 AI 대신 내부 모델을 선택하거나 해당 계정 연결을 해제하면 이전을 거부할 수 있으며, 이 경우 해당 외부 AI 기능은 사용할 수 없습니다.

5. Google 자료의 제한적 이용

EDU ONEQ Workspace가 Google API로부터 받은 정보와 그로부터 파생된 정보를 이용하고 다른 앱으로 전송하는 것은 Limited Use 요건을 포함한 Google API Services User Data Policy 및 Google Workspace API User Data and Developer Policy를 준수합니다. 해당 정보는 화면에서 제공하는 업무 기능을 수행하기 위한 목적으로만 사용합니다.

EDU ONEQ Workspace's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • 앱 운영자는 Google API로 받은 자료와 그 파생 정보를 해당 사용자에게 기능을 제공하기 위한 개인화 모델 외의 어떤 AI·머신러닝 모델의 생성·학습·개선에도 사용하지 않으며, 그 목적으로 전송하거나 판매하지 않습니다. 외부 AI 처리에도 앞 절의 보호 조건을 적용합니다.
  • Google 자료를 판매하거나 광고 타기팅·데이터 중개·신용평가에 사용하지 않습니다.
  • 사람이 자료 내용을 확인하는 것은 사용자가 특정 자료에 대해 동의한 지원·업무 처리, 보안 문제 대응 또는 법적 의무 이행 등 허용된 경우로 제한합니다.

이 방침의 게시나 OAuth 앱의 운영 상태 변경은 Google의 검증 심사 또는 보안 심사를 통과했다는 뜻이 아닙니다.

6. 저장 위치와 보호 방식

Google 인증 토큰은 운영 기기의 운영체제 보안 저장소(macOS Keychain)에 암호화해 보관하며, 공개 웹페이지나 일반 사용자 화면에 표시하지 않습니다. 문서 본문·검색 색인·일정·작업 기록은 운영자가 관리하는 운영 기기의 데이터베이스와 파일에 저장됩니다.

업무 포털에는 로그인과 접근 제한을 적용하고, 운영 기기에는 운영자의 사설 네트워크 안에서만 접속할 수 있으며, Google·외부 서비스와의 통신에는 암호화된 연결(HTTPS)을 사용합니다. 인증 토큰의 보호 방식과 업무 데이터의 저장 방식은 서로 달라, 데이터베이스·파일·백업 저장소에는 토큰 저장소와 같은 수준의 저장 시 암호화가 적용되지 않을 수 있습니다. 저장 시 암호화 범위를 넓히면 이 방침을 갱신합니다.

복구를 위해 운영 데이터의 백업이 만들어지며, 같은 사설 네트워크에 있는 운영자 관리 서버로 암호화된 연결(SSH)을 통해 복사됩니다. 백업에도 문서·일정·작업 기록이 포함될 수 있으므로 접근과 정리를 함께 관리합니다.

7. 보관 기간과 정리

문서 본문 캐시
기본 설정은 마지막 접근 후 30일을 정리 기준으로 사용하며, 용량 제한도 적용합니다. 정리는 Google 연결이 유효한 상태에서 동기화·미리보기가 처리될 때 함께 실행되므로 정확히 30일이 되는 순간 삭제되는 방식은 아닙니다. Google 연결이 만료·철회되어 동기화가 멈춘 동안에는 자동 정리도 실행되지 않으며, 남은 캐시와 검색용 본문은 다시 연결한 뒤 정리되거나 8절의 삭제 요청으로 처리합니다. 운영 설정에 따라 기준이 달라질 수 있습니다.
파일 색인과 일정
동기화 결과에 따라 갱신·정리합니다. 일정은 선택한 캘린더와 조회 범위에 맞춰 저장되며, 연결 오류 때 이전 정보를 표시할 수 있습니다. 문서 본문 캐시와 보관 기준이 동일하지 않습니다.
대화·작업 자료와 결과
사용자가 이어서 업무를 수행하고 처리 근거를 확인할 수 있도록 보관합니다. 작업에 사용된 본문 사본과 결과는 원본이나 캐시와 별개로 남을 수 있으며, 전체 기록에 일괄 적용되는 자동 만료 기간은 없습니다.
백업과 보존이 필요한 기록
운영 복구 기준에 따라 별도로 보존·정리합니다. 자동 백업 외에 수동 백업이나 별도 사본이 남을 수 있습니다. 삭제 요청 시 확인되는 보관 위치와 처리 범위를 함께 안내합니다.

Google 권한 철회, 원본 파일 삭제 또는 검색 범위 변경만으로 위 데이터가 모두 소급 삭제되는 것은 아닙니다.

파기 방법: 보관 목적이 끝났거나 삭제 요청을 확인한 정보는 데이터베이스·캐시·파일에서 복구할 수 없는 방법으로 삭제합니다. 백업에 남은 사본은 백업 정리 주기에 맞춰 삭제하며, 법령상 보존이 필요한 경우 그 근거와 항목을 안내합니다.

8. 연결 해제와 데이터 삭제 요청

    운영자에게 데이터 삭제를 요청해 주세요. 연결 계정, 대상 자료·프로젝트·대화와 삭제를 원하는 범위를 알려주시면 요청 권한을 확인하고 남은 데이터와 처리 범위를 안내합니다. 비밀번호·인증 토큰이나 민감한 원문 전체를 이메일에 넣지 마세요.

    연결 정보만이 아니라 본문 캐시, 검색 색인, 일정, 대화·작업 자료, 내보낸 파일과 백업 중 무엇을 정리해야 하는지 확인합니다. 업무 화면에서는 내용이 없는 새 대화만 직접 지울 수 있으므로, 내용이 있는 대화와 작업 기록의 삭제는 위 2번의 방법으로 운영자에게 요청해 주세요.
